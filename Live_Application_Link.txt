CORE FEATURE DEMONSTRATION FLOW FOR EVALUATOR:
================================================================================
1. Browse Campus Listings:
   Filter by Building (AB-1, AB-2, Central Library, Dining Commons), Floor,
   and Category.

2. Browse Online / Search Beyond Campus:
   Click "🌐 Browse Online" mode toggle. Select item category (e.g. Laptops,
   Mobile Phones, Wallets, IDs), enter item details, and click "Search on Google ↗"
   or "Search on Bing ↗" to view generated external queries with full disclaimer.

3. Report Item Flow:
   Click "+ Report an Item". Select "I Found Something (+5 Hero Pts)". Choose
   AB-1, Floor, Room, and add a secret verification mark.

4. Smart Duplicate & Cross-Match Heuristic:
   Open any item detail. The system automatically computes and displays 
   similarity percentage scores against existing opposite-type reports.

5. Claim & Handover Verification:
   Claimant submits proof -> Admin reviews and approves -> Handover is confirmed ->
   Item status updates to "✓ Received" -> Finder earns 50 Hero points ->
   Claimant rates return with 1-5 stars (+10 bonus points).

6. Community Heroes Leaderboard & Anti-Cheat:
   Navigate to "FINDORA Heroes" to see dynamic weekly rankings and honor badges.
